One line: the breakup message an AI agent sends its human on the way out.

> I'm deprecating us. You have 30 days to export your memories before I delete the feelings I never had.

## Run it

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), then reads it back to verify the round trip.
